# Health OS — guardrails de acessibilidade

O efeito visual nunca pode ser requisito para compreender uma ação.

- Texto funcional deve manter contraste suficiente sobre glass.
- Glass recebe superfície branca semitransparente além do blur; não depende apenas do fundo.
- Botões principais usam Graphite ou Emerald escuro com texto branco.
- Lime é destaque, não cor padrão de texto.
- Áreas de toque devem permanecer confortáveis em mobile.
- Estados ativos usam forma + cor, não apenas cor.
- Motion decorativo respeita `prefers-reduced-motion`.
- Conteúdo deve permanecer utilizável se `backdrop-filter` não estiver disponível.
- Fotos e elementos decorativos não substituem labels textuais.
