# Health OS v3 — release notes

- Busca e resultados receberam acabamento mobile de app.
- Filtros expandidos usam apresentação de bottom sheet sem alterar a lógica de query string.
- Cards de profissionais e empresas foram refinados para densidade, toque e hierarquia mobile.
- Perfil profissional recebeu hero compacto e seções consistentes com Health OS.
- Contatos reais de locais receberam CTA mais evidente; nenhuma informação nova foi criada.
- Microinterações de toque e animação sutil do orb foram adicionadas.
- `prefers-reduced-motion` continua respeitado.
- Inputs de busca usam 16px no mobile para evitar zoom automático no iOS.
- Estados `focus-visible` foram reforçados.
