# Health OS — hierarquia de conteúdo

1. Contexto de cidade.
2. Busca por atendimento.
3. Atalhos assistenciais.
4. Descoberta de profissionais e serviços.
5. Conteúdo editorial.
6. Ações secundárias e institucionais.

Essa ordem é a regra para a Home mobile. Conteúdo editorial não deve empurrar a busca por atendimento para baixo.
