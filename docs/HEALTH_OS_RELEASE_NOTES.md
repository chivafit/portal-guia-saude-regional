# Health OS v1 — release notes

Esta fase conclui a primeira linguagem de produto do novo Guia Saúde sem fechar a logo definitiva.

### Entregue
- Home mobile-first high-tech.
- Sistema cromático Emerald / Aqua / Lime / Ice / Graphite.
- Liquid glass e profundidade aplicados com moderação.
- Floating dock de cinco destinos.
- Busca, filtros e resultados com nova camada visual.
- Perfil profissional e estabelecimento integrados ao sistema.
- Favoritos integrados ao sistema.
- Microanimações com fallback de movimento reduzido.
- Documentação de princípios, interações e QA.

### Preservado
- Dados públicos existentes.
- SEO e rotas públicas.
- Query strings e lógica de busca.
- Favoritos locais.
- Contatos e links de perfis/estabelecimentos.

### Adiado intencionalmente
- Logo/app icon definitivo.
- Alterações profundas na arquitetura editorial.
- Novos recursos que dependam de backend.
