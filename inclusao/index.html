Fluxo de validação

Solicitar não publica automaticamente.

O Guia Saúde é um portal informativo. Toda inclusão precisa passar por revisão antes de aparecer publicamente.

  1. Você envia os dados básicos.
  2. A equipe revisa as informações.
  3. O cadastro pode ir para validação.
  4. Após aprovação, o perfil pode ser publicado no guia.
