# Metodologia — base demonstrativa regional

Status: rascunho visual e comercial para validação.

## Objetivo

Preencher os miniportais das cidades com volume mínimo de profissionais, empresas e serviços para:

- validar layout;
- demonstrar espaços comerciais;
- apresentar categorias vendáveis;
- permitir substituição futura por cadastros reais.

## Escopo aplicado

Cidades:

- Piumhi
- Capitólio
- Pimenta
- Arcos
- Campo Belo
- Bambuí
- São Roque de Minas

## Regra editorial

Perfis com nome "Perfil demonstrativo" não representam pessoas reais.

Eles existem apenas para mostrar:

- foto substituível;
- conselho profissional pendente;
- especialidade;
- cidade;
- serviços;
- botão de contato;
- estrutura comercial do card.

Empresas/serviços com "demonstrativo" no nome também não devem ser vendidos como cadastro real.

## Antes da publicação comercial

Cada cadastro real precisa de:

1. nome oficial;
2. categoria correta;
3. cidade;
4. endereço;
5. telefone/WhatsApp;
6. fonte;
7. autorização ou validação do responsável quando for perfil privado;
8. foto/logo/capa autorizados.
